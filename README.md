# SGCC-INSS-Estagio
Este repositório contém o código-fonte do Sistema de Gerenciamento e Catalogação de Computadores (SGCC-UFAC), desenvolvido para a Gerência Executiva do Instituto Nacional do Seguro Social (INSS) no Acre. Sistema criado como parte de um estágio supervisionado do curso de Bacharelado em Sistemas de Informação da Universidade Federal do Acre (UFAC).
